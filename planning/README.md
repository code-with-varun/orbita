## Core Planning Modules & Scoping

1. **Executive Work Item Framework**:
   - 4-Item Unified Hierarchy: **Tasks**, **Routines** (recurring), **Goals** (milestones), **Projects** (multi-stage).
   - Eisenhower 2x2 Priority Matrix (Q1 Urgent/Important, Q2 Focus, Q3 Delegate, Q4 Eliminate).
2. **Productivity & Time Governance**:
   - Live Focus Timer & Timesheets with sub-second stopwatch tracking.
   - Executive Dashboard with completion metrics, velocity graphs, and status filters.
3. **Asset & Vault Governance**:
   - **Subscription Manager**: SaaS tracking, auto-renewal alerts, and billing history.
   - **Warranty Manager**: Physical asset records, condition tracking, and expiration monitors.
   - **Credential Vault**: AES-256 encrypted passwords, cyber codes, and MFA tracking.
   - **Contact Manager**: Address book, social IDs, duplicate detection & Google sync.
4. **Data Privacy & User Sovereignty**:
   - Table-wise Multi-Sheet Excel Export (`.xlsx`) dumping all logged-in user data into individual sheets.
   - Complete Password Reset workflow in profile settings and authentication screens.
